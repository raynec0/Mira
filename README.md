# Mira — iMessage 风格的私人 AI 智能体（iOS）

一个类似 Meta Muse 的个人 Agent App：像发 iMessage 一样把事情交给它，它会调用工具真正把事办完；敏感操作先请你批准，所有动作都有审计记录。

## 界面

- **iOS 26/27 iMessage 风格**：对话列表（置顶头像网格、未读蓝点、左右滑动操作、搜索）、蓝灰气泡带尾巴、时间分隔、"已送达/已读"、正在输入三点动画、双击 ❤️ 回应 / 长按 Tapback、引用回复。
- **Liquid Glass**：用 Xcode 26+ 编译时，"+" 按钮、输入框、快捷指令面板使用原生 `glassEffect`，TabView / 导航栏自动获得液态玻璃；旧版本系统自动回退到磨砂材质。
- **聊天交互**：悬浮胶囊输入栏、原位展开的附件菜单、向左滑动消息引用回复；向上翻阅历史时暂停自动跟随，点右下角箭头回到最新消息。生成中仍可编辑下一条草稿，并随时停止回复。
- **可读性**：蓝灰内容气泡保持实色；玻璃用于导航和操作控件。支持深色模式、动态字体、VoiceOver，以及系统“减少透明度 / 减弱动态效果”。
- 四个标签页：**信息 / 任务 / 动态 / 设置**。

## 功能

| 模块 | 说明 |
|---|---|
| 双模型服务商 | OpenAI 兼容接口（OpenAI、DeepSeek、通义、Kimi、OpenRouter、Ollama…）与 Anthropic Claude，流式输出 + 原生工具调用，可在线拉取模型列表；每个智能体可单独指定服务商/模型/温度 |
| 多智能体 | 预置 Mira、研究员、日程管家、写作助手、代码助手；可自建（头像、颜色、人设、可用工具、最大步数） |
| Agent 循环 | 模型 ↔ 工具多轮自动循环，可随时停止；思考过程（reasoning）可折叠查看 |
| 批准机制 | 每个工具可设为 自动 / 每次询问 / 禁用；询问时在对话中弹出批准卡片（拒绝 / 始终允许 / 允许），App 在后台时推送通知 |
| 动态（审计） | 每次工具调用的参数、结果、状态全部记录，可追溯到对话 |
| 任务 | 智能体把大目标拆成步骤并持续更新进度；可手动编辑、勾选步骤，一键"让智能体继续推进" |
| 例程 | 定时让智能体执行指令（如工作日 7:30 早间简报），到点通知，前台/后台刷新自动执行 |
| 记忆 | 智能体自动记住你的偏好，可在设置中查看、编辑、删除 |
| 连接器 | 把任意 HTTP API 接入给智能体（认证头保存在钥匙串，智能体看不到明文） |
| 快捷指令 | 输入 `/` 调出提示词模板，支持 `{{input}}` |
| 输入方式 | 文字、语音听写、照片、相机、文件（含 PDF 文本提取）、当前位置 |
| 其他 | 朗读回复、面容 ID 锁、备份导出/恢复、对话导出文字、置顶/静音/重命名/切换智能体 |

## 构建（和 RetroMail 相同的流程）

1. 新建一个 GitHub 仓库，把本目录全部内容推上去（包括 `.github` 文件夹）。
2. GitHub Actions 会自动运行 **Build IPA**（也可在 Actions 页手动触发）。
3. 在运行结果的 Artifacts 里下载 `Mira-ipa`，解压得到未签名的 `Mira.ipa`，用你平时的自签工具安装。

本地构建：`brew install xcodegen && xcodegen generate`，然后用 Xcode 打开 `Mira.xcodeproj`。

- 最低系统：iOS 17；用 Xcode 26 及以上编译可获得原生 Liquid Glass 效果。
- Bundle ID：`com.raynec.mira`（在 `project.yml` 中修改）。

### 预览与验证

在 Xcode 打开 `ChatStylePreview.swift` 的 Canvas，可预览浅色、深色、大字体三种状态，发送操作仅修改预览内存，不调用模型。“减少透明度 / 减弱动态效果”需在模拟器或真机的系统辅助功能设置中测试。Liquid Glass 使用 iOS 26 起提供的系统 API，在后续系统上由系统渲染；没有使用假定的 iOS 27 专属接口。

CI 使用 Xcode 26.0，并先在 iPhone 模拟器运行消息分组测试，再构建 IPA。本地可运行：

```sh
xcodegen generate
xcodebuild test -project Mira.xcodeproj -scheme Mira -destination 'platform=iOS Simulator,name=iPhone 17 Pro' CODE_SIGNING_ALLOWED=NO
```

真机验收重点：长回复生成中上翻不应被拉回底部；下拉到末尾恢复跟随；键盘和附件菜单切换不遮住最后一条消息；左滑消息只触发一次引用回复；草稿存在时仍可停止生成。iOS 17 验证材质回退，iOS 26 及以上验证原生玻璃和系统导航过渡。

## 首次使用

1. 打开 **设置 › 模型服务**，填写 OpenAI 兼容接口的 Base URL、API Key 与模型（或填写 Anthropic Key），点"选择"可在线拉取模型。
2. 可选：填写 Tavily Key 获得更稳定的网页搜索；配置图像生成。
3. 在 **设置 › 权限与批准** 里调整每个工具的执行策略。
4. 回到 **信息**，和 Mira 说一件要办的事，例如：
   - "帮我查一下明天深圳的天气，下雨的话提醒我早上带伞"
   - "我想在 3 个月内准备好 PMP 考试，帮我做个计划并跟进"
   - "每个工作日早上 7:30 给我一份简报"

## 说明

- 所有数据只保存在本机（对话在 Application Support，API Key 在钥匙串，生成的文档在"文件 App › Mira"）。
- iOS 不允许 App 长时间常驻后台：智能体在你切走后还能继续约 30 秒；例程依靠通知 + 系统后台刷新 + 回到前台时补跑来执行。
- 发送邮件/短信最终都会弹出系统编辑器，由你按下发送。
